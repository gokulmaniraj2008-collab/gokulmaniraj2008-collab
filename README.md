## Who I Am

I'm **Gokul**, a second-year college student in Tamil Nadu, India, and founder of **GKFXL**. I build practical products aimed at Indian users — especially rural communities and students — end to end, from database design to UI to deployment.

<br/>

## What I'm Building

**GKFXL** — a consolidated Next.js + Supabase platform with two core pieces:
- **Academy** — a public learning funnel that moves users from learner to team member
- **Founder Dashboard** — an internal operating system for running the startup itself

**GGE** (evolved from an earlier project, DRYNN) — an AI guidance platform built for rural Indian users.
